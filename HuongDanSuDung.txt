HƯỚNG DẪN SỬ DỤNG
==================

1. CÁCH CHẠY KHUYẾN NGHỊ

Cách chạy đầy đủ và được khuyến nghị là sử dụng notebook:

MaDeTai/src/thesis_final.ipynb

Notebook gọi trực tiếp các chương trình Python trong thư mục project, thay vì triển khai lại thuật toán trong các cell.

Trình tự pipeline:

1. Kiểm tra môi trường.
2. Xác định đường dẫn BTXRD và SAM checkpoint.
3. Tạo hoặc kiểm tra split manifest.
4. Huấn luyện classifier DenseNet121.
5. Đánh giá classifier.
6. Sinh LayerCAM và prompt.
7. Chạy SAM để tạo pseudo-mask.
8. Đánh giá pseudo-mask.
9. Sinh pseudo-mask cho tập train.
10. Huấn luyện U-Net bằng pseudo-mask.
11. Đánh giá U-Net trên validation.
12. Khóa cấu hình.
13. Chạy một lần trên tập test.
14. Chạy inference U-Net trên ảnh mới.

5. HUẤN LUYỆN CLASSIFIER

Lệnh canonical:

python train_classifier.py \
  --pipeline-profile btxrd_hybrid \
  --data-root /duong/dan/BTXRD \
  --split-manifest /duong/dan/split_manifest.csv \
  --output-dir /duong/dan/output/classifier_run

Profile btxrd_hybrid cố định các thông số chính:
- Nhãn: tumor_type.
- Số lớp: 10 lớp, gồm normal và 9 loại u.
- Kích thước ảnh classifier: 320.
- Batch size: 4.
- Số epoch tối đa: 25 theo cấu hình hiện tại.
- Early stopping patience: 7.
- Learning rate: 1e-4.
- Weight decay: 1e-4.
- Seed: 42.
- PuzzleCAM loss: bật theo profile.
- Teacher-Student attention distillation: bật theo profile.
- Khởi tạo ImageNet: bật.
- Augmentation và random erasing: tắt trong profile canonical.

Có thể xem toàn bộ tham số:

python train_classifier.py --help

Output chính thường gồm:
- best_classifier.pt
- checkpoint theo epoch hoặc checkpoint cuối.
- lịch sử huấn luyện.
- metric train/validation.
- thông tin provenance và hash split manifest.


6. ĐÁNH GIÁ CLASSIFIER

python evaluate_classifier.py \
  --data-root /duong/dan/BTXRD \
  --split val \
  --split-manifest /duong/dan/split_manifest.csv \
  --checkpoint /duong/dan/output/classifier_run/best_classifier.pt \
  --output-dir /duong/dan/output/classifier_val

Các output chính:
- per_image.csv
- multiclass_confusion.csv
- summary.json
- run_manifest.json

Báo cáo gồm:
- Metric phân loại 10 lớp.
- Tumor-vs-normal gate.
- Accuracy, precision, recall, specificity và F1.
- AUROC và AUPRC.
- Bootstrap confidence interval.

Đối với test split, cần cung cấp frozen config theo cơ chế bảo vệ của chương trình.


7. SINH PSEUDO-MASK CHO VALIDATION

python generate_pseudo_masks.py \
  --pipeline-profile btxrd_hybrid \
  --data-root /duong/dan/BTXRD \
  --split-manifest /duong/dan/split_manifest.csv \
  --split val \
  --classifier-checkpoint /duong/dan/output/classifier_run/best_classifier.pt \
  --sam-checkpoint /duong/dan/sam_vit_b_01ec64.pth \
  --cam-target-class ground_truth \
  --process-all \
  --output-dir /duong/dan/output/pseudo_val

Pipeline pseudo-mask gồm:
- LayerCAM đa tầng.
- Class-vs-normal contrast.
- Percentile threshold ensemble.
- Connected components.
- Prompt điểm dương, điểm âm và box.
- SAM v1 ViT-B.
- Prompt ensemble.
- Chọn mask bằng coverage_mass_sam.
- Hậu xử lý hình thái học.
- Ghi manifest và hash cho mỗi pseudo-mask.

Output chính:
- masks/: pseudo-mask PNG.
- overlay hoặc ảnh trực quan hóa.
- run_metadata.json.
- pseudo-mask manifest.
- danh sách skipped_low_confidence nếu có.
- các file diagnostic.

10. HUẤN LUYỆN U-NET BẰNG PSEUDO-MASK

python train_segmentation.py \
  --pipeline-profile btxrd_hybrid \
  --data-root /duong/dan/BTXRD \
  --split-manifest /duong/dan/split_manifest.csv \
  --train-pred-mask-root /duong/dan/output/pseudo_train/masks \
  --output-dir /duong/dan/output/unet_run

Các tham số chính:
- Train split: train.
- Validation split: val.
- Loss: BCE + Dice.
- Checkpoint chính được chọn theo val_positive_dice.
- Khi Dice gần bằng nhau, normal empty-case specificity được dùng để phân xử.
- Có thể bật --multi-gpu khi có nhiều GPU.
- Có thể dùng --early-stop-patience để dừng sớm.

Lưu ý:
- Không được thiếu pseudo-mask của ảnh train.
- Manifest pseudo-mask phải khớp split, kích thước ảnh và hash.
- Polygon validation được dùng để đánh giá và chọn checkpoint U-Net.

12. CHẠY TẬP TEST ĐÃ KHÓA

Tập test chỉ chạy sau khi:
- Profile đã được chọn.
- Classifier checkpoint đã được khóa.
- U-Net checkpoint đã được khóa.
- Split manifest không thay đổi.
- Frozen config đã được tạo.
- Các hash checkpoint và manifest khớp.

Ví dụ đánh giá U-Net trên test:

python evaluate_unet.py \
  --data-root /duong/dan/BTXRD \
  --split-manifest /duong/dan/split_manifest.csv \
  --split test \
  --frozen-config /duong/dan/frozen_config.json \
  --checkpoint /duong/dan/output/unet_run/best_unet.pt \
  --output-csv /duong/dan/output/unet_test/per_image.csv \
  --output-json /duong/dan/output/unet_test/summary.json

Không dùng test để điều chỉnh threshold, epoch, profile hoặc siêu tham số.

15. XỬ LÝ LỖI THƯỜNG GẶP

15.1. Không tìm thấy dữ liệu

Kiểm tra:
- --data-root.
- Thư mục images.
- Thư mục Annotations.
- File metadata CSV/XLSX.
- Tên ảnh trong metadata.

15.2. Không tìm thấy SAM checkpoint

Kiểm tra:
- --sam-checkpoint.
- Quyền đọc file.
- Checkpoint đúng model ViT-B.

15.3. CUDA out of memory

Thử:
- Giảm batch size khi không dùng profile khóa.
- Giảm num-workers.
- Tắt --multi-gpu nếu cấu hình không phù hợp.
- Khởi động lại session Kaggle.
- Xóa tensor/model không còn sử dụng giữa các stage.

15.4. Split manifest hash mismatch

Không tạo split mới giữa pipeline.
Dùng lại đúng file split_manifest.csv đã dùng khi train checkpoint.

15.5. Pseudo-mask manifest mismatch hoặc thiếu mask

Không sao chép riêng thư mục masks mà bỏ manifest.
Không đổi tên file.
Chạy lại stage sinh pseudo-mask nếu artifact bị thiếu hoặc thay đổi.

15.6. Test split bị từ chối

Cung cấp:
- --frozen-config.
- Đúng split manifest.
- Đúng checkpoint đã ghi trong frozen config.
- Biến hoặc cờ khóa test theo notebook nếu pipeline yêu cầu.

15.7. Lỗi import Segment Anything

Cài lại:

python -m pip install -r requirements.txt

Hoặc cài Segment Anything từ wheel/source local nếu Kaggle Internet tắt.


16. NGUYÊN TẮC BÁO CÁO KẾT QUẢ

- Classifier: báo cáo macro-F1 và tumor-gate AUROC/AUPRC, sensitivity, specificity.
- Pseudo-mask/U-Net: ưu tiên Dice và IoU trên tumor-only.
- Ảnh normal: báo cáo specificity hoặc false-positive rate riêng.
- Không dùng Dice gộp normal và tumor làm metric chính vì ảnh normal có thể làm tăng trung bình.
- Validation là development set.
- Test là báo cáo cuối và chỉ chạy một lần sau khi khóa cấu hình.
