HƯỚNG DẪN CÀI ĐẶT
==================

1. PHẠM VI

Nhánh main chỉ chứa pipeline WSSS chính thức:

nhãn ảnh nhị phân tumor
-> DenseNet121
-> LayerCAM + flip TTA
-> SAM ViT-B
-> pseudo-mask
-> ResNet18 U-Net.

Mô hình fully supervised chỉ là upper-bound diagnostic, không phải kết quả
WSSS của luận văn.

2. MÔI TRƯỜNG

Các tác vụ GPU nặng phải chạy trên Kaggle. Môi trường đã dùng cho kết quả
validation:

- Python 3.12.13
- PyTorch 2.10.0+cu128
- torchvision 0.25.0+cu128
- CUDA 12.8
- GPU Tesla T4

Cài dependency từ repository:

python -m pip install -r project/requirements.txt

3. INPUT KHÔNG ĐƯA VÀO GIT

- BTXRD: images/, Annotations/ và bảng metadata.
- SAM ViT-B checkpoint.
- Classifier và U-Net checkpoint.
- Cache, tmp, output Kaggle, token và secret.

Kiểm tra checkpoint bằng hash trong:

artifacts/official_wsss/checkpoints/checkpoint_pointer.json

Checkpoint U-Net WSSS chính thức:

SHA256 02d3af8feede3c3e650cb76d664185c59092697c1c8306ea67613b89f8407fb4
bytes  230924939

4. KIỂM TRA CÀI ĐẶT

python -m compileall -q project tests
python -m unittest discover -s tests -v

Máy local thiếu PyTorch/SciPy không được xem là đã PASS đầy đủ. Verifier,
unit test và smoke test đầy đủ phải chạy trên Kaggle trước lần đánh giá test.

5. NGUYÊN TẮC TEST

Không truy cập test trước khi file configs/official_wsss_frozen_test.json đã
được tạo từ working tree sạch và commit. Không sweep threshold trên test.
Chỉ checkpoint WSSS, image size 448 và threshold validation 0.85 được phép.
